## 1. Solution Overview

A scheduled API Workflow that runs weekdays at 10:00 Europe/Bucharest, queries Coupa for invoices (past seven days, status draft or new), excludes credit notes and invoices with linked POs, counts the remainder, and sends a Slack Block Kit notification to member WLX9BD8FN if count > 0. Read-only on Coupa; no modifications.

## 2. As-Built Architecture

The workflow computes a 7-day window, fetches invoices from Coupa via HTTP GET, filters in JavaScript, and branches on count. If qualifying invoices exist, it composes a Slack Block Kit message and posts to `chat.postMessage`; otherwise it returns silently.

```
Workflow: no-po-invoice-chaser-api
├─ JavaScript: Compute date window (today ±7d)
├─ HTTP GET: Coupa /invoices (connector: uipath-coupa-coupa)
├─ JavaScript: Filter & count (exclude credit notes, exclude PO-linked)
├─ Branch: if count > 0
│  ├─ JavaScript: Compose Slack Block Kit
│  ├─ HTTP POST: Slack /chat.postMessage (connector: uipath-salesforce-slack)
│  └─ JavaScript: Validate Slack response (ok=true)
└─ Response: {status, qualifying_count, slack_sent}
```

**No deviations from SDD.** Workflow implements BR-01 through BR-09 as specified.

## 5. Operations Runbook

**Prerequisites:**

- Coupa connection registered in Orchestrator under ID `5fadfc73-a372-46ae-a27c-2481741eed07` with API key/token stored in Orchestrator assets
- Slack bot token stored in Orchestrator assets; bot has `chat:write` permission and can DM member `WLX9BD8FN`
- Orchestrator scheduler configured with a trigger named `no-po-invoice-chaser-api` at weekday 10:00 Europe/Bucharest (IANA zone)
- No open TODOs in code; all variable names and payloads match the workflow schema

**Trigger and Schedule:**

Orchestrator job scheduler, weekdays only, 10:00 Europe/Bucharest. No manual queue submission. Duration: ~5–10 seconds (Coupa fetch + Slack POST).

**Expected Run Behavior:**

1. Workflow starts; computes a 7-day window (today minus 7 days to today)
2. Queries Coupa for draft/new invoices within that window, limit 50
3. Filters: removes credit notes, removes invoices with linked POs
4. If count > 0: composes Slack message with count, policy explanation, action button to Coupa query, footer with dates; posts to channel WLX9BD8FN
5. Returns output: `{status: "Successful", qualifying_count: <n>, slack_sent: true|false}`

**Logs to check (Orchestrator):**

- `qualifying_count=<n>` — count of invoices with no linked PO
- `slack_sent=true|false` — whether notification was delivered
- HTTP errors from Coupa (5xx, 403, timeout) or Slack (non-200, non-ok) will appear as exception logs and mark the run as failed

**Normal run (invoices found):**
```
qualifying_count=3
slack_sent=true
```

**Normal run (clean day):**
```
qualifying_count=0
slack_sent=false
```
