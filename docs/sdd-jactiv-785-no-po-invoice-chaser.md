## 1. API Workflow Overview

Weekday automation that runs at 10:00 Europe/Bucharest, queries Coupa for invoices (past seven days, status draft or new), excludes credit notes, identifies those with no properly linked purchase order, counts them, and sends one Slack Block Kit direct message to Irina Capatina (member ID WLX9BD8FN) if count > 0. Sends nothing on a clean day. Read-only access; no Coupa modifications.

**Trigger:** Orchestrator scheduler, weekday 10:00 Europe/Bucharest (IANA zone)

**Outcome:** Message delivered to Slack or silent completion (count = 0)

## 8. Testing Strategy

### Happy path

| Test case | Input | Expected | Validates |
|---|---|---|---|
| Query returns qualifying invoices | Coupa responds with draft/new invoices; some lack linked PO | Message sent to Slack with correct count; ok=true in response | Steps 3–11; BR-04, BR-06 |
| Query returns no qualifying invoices | Coupa responds; all have linked PO or are filtered out | No Slack message; slackSent=false; run completes silently | Steps 3–6; BR-07 |

### Business exceptions

| Exception | Trigger | Expected | Validates |
|---|---|---|---|
| Credit notes excluded | Coupa invoice has invoice-type = "Credit Note" | Invoice omitted from count | Step 4; BR-03 |
| PO in description only | Invoice lines have no po-number/order-header-num but description mentions PO | Invoice included in count as missing PO | Step 4; BR-02 |
| Clean day (zero count) | All returned invoices have linked PO or are credit notes | Output count=0; no Slack message sent; slackSent=false | Steps 4–6; BR-07 |

### System errors

| Error | Trigger | Expected | Validates |
|---|---|---|---|
| Coupa 5xx or timeout | HTTP error at step 3 | Run marked failed; no Slack sent | Step 3; BR-09 |
| Coupa 401/403 | Auth failure at step 3 | Run marked failed; logged to Orchestrator | Step 3; BR-10 |
| Slack API non-200 | HTTP error at step 9 | Run marked failed; logged | Step 9; BR-09 |
